# Sample Datasets (AdventureWorks & WideWorldImporters)

Dieser Ordner enthält Installationsanleitungen und Bereitstellungsskripte für standardisierte Microsoft SQL Server Beispieldatenbanken.

---

## 1. 🏢 AdventureWorks2022

Die offizielle Microsoft-Referenzdatenbank für komplexe Abfragen, Vertriebsanalysen und Data Warehousing.

* **Download:** [AdventureWorks2022.bak (Microsoft GitHub Releases)](https://github.com/Microsoft/sql-server-samples/releases/download/adventureworks/AdventureWorks2022.bak)
* **Wiederherstellung:** Führen Sie das Skript estore_adventureworks.sql in SSMS aus.

---

## 2. 🌍 WideWorldImporters

Die moderne Microsoft OLTP- und Data Warehouse-Beispieldatenbank mit realistischen Handels- und Bestelldaten.

* **Download:** [WideWorldImporters-Full.bak (Microsoft GitHub Releases)](https://github.com/Microsoft/sql-server-samples/releases/download/wide-world-importers-v1.0/WideWorldImporters-Full.bak)
* **Wiederherstellung:** Führen Sie das Skript estore_wideworldimporters.sql in SSMS aus.
